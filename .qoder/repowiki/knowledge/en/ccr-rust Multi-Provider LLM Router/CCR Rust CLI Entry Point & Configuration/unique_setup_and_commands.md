Binary is invoked as `ccr-rust`; default config path is `~/.claude-code-router/config.json` (overridable via `--config` or `CCR_CONFIG` env var). Subcommands include `start`, `validate`, `status`, `doctor`, `dashboard`, `workers`, `clear-stats`, `mcp`. Environment variables control runtime behavior (`CCR_MAX_STREAMS`, `CCR_DASHBOARD_HOST`, `CCR_DASHBOARD_PORT`, `CCR_REDIS_URL`, `CCR_ALLOW_UNEXPANDED_CREDENTIALS`).
