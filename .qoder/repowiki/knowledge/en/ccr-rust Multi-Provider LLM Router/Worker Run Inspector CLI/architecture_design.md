Four internal layers with one-way dependencies: `stream.rs` provides a cursor-aware line scanner over `events.jsonl`; `report.rs` consumes the stream to build typed summary structures (Usage, recent/failure queues, salvage hints) and exposes `list_entry`, `summarize`, `events`, `detail`; `render.rs` formats the resulting `serde_json::Value` into human-friendly text; `mod.rs` wires clap `WorkerArgs`/`WorkerCommand` subcommands (`list`, `show`, `events`, `detail`) to those layers and dispatches either JSON serialization or text rendering. Runs are discovered under `~/.cache/ccr-worker-runs` by scanning directories containing the expected artifact set, sorted by ISO-like timestamp prefix then by name. Tests live in sibling `*_tests.rs` modules gated by `#[cfg(test)] #[path = ...]` so each source file owns its tests without extra crate layout.
