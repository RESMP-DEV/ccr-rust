The HTTP daemon reads `EXA_API_KEY` and `JINA_API_KEY` from the environment and accepts Jina search/reader base URLs via struct fields; Pyright requires both `--pyright-root` and `--pyright-workspace-dir` (or env vars `CCR_MCP_PYRIGHT_WORKSPACE_DIR`). The stdio server requires at least one backend command in its `backends` list and forwards each newline-delimited JSON-RPC frame to the corresponding child process.
