Flat collection of crate-level `integration_*` and `test_*` Rust test modules under `tests/`, with two supporting subdirectories: `mocks/` provides synthetic OpenAI-format request builders (e.g. `codex_client.rs`) and a Claude Code mock (`claude_code_client.rs`), while `support/` exports shared harness helpers (`build_app`, `make_codex_stream_request`, SSE frame parsing) re-exported from `support/mod.rs`. The entry point `lib.rs` only exposes the `mocks` module; each `integration_*.rs` file is an independent `#[tokio::test]` suite that spins up a local Axum router backed by `wiremock::MockServer` to validate request/response transformations across providers (Codex, Claude Code, Meta, Kimi, Doctor, Preset CLI). `provider_validation/validate_apis.py` is an optional Python script for probing live Z.AI / MiniMax APIs and recording response shapes. Dependency direction is one-way: test crates depend on the compiled library via Cargo's default test-binary linking and use wiremock as a stub backend rather than calling real providers.
